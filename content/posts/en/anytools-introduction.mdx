# AnyTools: Discover the Best Tools

> A curated tool navigation platform to help you find the right tools faster.

---

## 🎯 Background

As an indie developer, I constantly switch between different tools. Finding, comparing, and choosing tools took up way too much time.

So I built **AnyTools** — a tool navigation platform that centralizes all the tools I use, making it easier for myself and others.

## 🛠️ Tech Stack

```
Framework:  Next.js 16 (App Router)
Language:   TypeScript
Styling:    Tailwind CSS v4
Animation:  Framer Motion
UI:         shadcn/ui
Icons:      Lucide Icons
Search:     Client-side search
Deployment: Vercel
```

**Technical Highlights:**
- Static generation for blazing fast loading
- Responsive design, mobile-friendly
- Real-time search, quick navigation
- Theme switching, light/dark mode
