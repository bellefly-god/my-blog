# AnyTools：发现最好的工具

> 一站式工具导航平台，帮你快速找到最适合的工具。

---

## 🎯 项目背景

作为独立开发者，我经常需要在各种工具之间切换。找工具、比工具、选工具，耗费了大量时间。

于是我做了 **AnyTools** —— 一个工具导航平台，把常用的工具集中整理，方便自己，也方便他人。

---

## 🚀 使用场景

### 场景 1：找 AI 工具

想找一个 AI 编程助手？进入「AI 工具」分类，快速浏览 Cursor、GitHub Copilot、Claude Code 等选项，对比功能，选择最适合的。

### 场景 2：发现新项目

每周看看 GitHub 增长榜，了解最新热门项目，跟上技术趋势。

### 场景 3：提升效率

需要截图工具？PDF 处理？图片压缩？在「效率工具」或「生活小工具」里快速找到。
